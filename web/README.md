# Web UI

The browser interface for the Pi: Spotify, internet radio, config and status.

Python standard library on the server (`server.py`, `api/`), plain HTML, CSS and JavaScript in
`static/`. Runs as the `spotify-dac-web` service over HTTPS.

Design: [../docs/web-ui-plan.md](../docs/web-ui-plan.md). Pages: [../docs/web-ui/](../docs/web-ui/).
